Browser Local Storage Inspector

All players, fixture schedules, and single-set scores are securely saved in your browser's localStorage under the key shatin_big_league_v1.

Google Chrome & Brave

  1. Right-click anywhere on the page and select Inspect (or press F12).
  2. Click on the Application tab at the top of the developer panel.
  3. In the left sidebar, expand Local Storage under the Storage section.
  4. Click on this website's domain URL to view the stored JSON key shatin_big_league_v1.

Apple Safari

  1. Enable the Develop menu in Safari Settings > Advanced > Show Develop menu in menu bar.
  2. Open Develop > Show Web Inspector.
  3. Go to the Storage tab.
  4. Select Local Storage in the sidebar to inspect league items.

Mozilla Firefox

  1. Right-click and choose Inspect (Q).
  2. Navigate to the Storage tab in the dev tools.
  3. Expand Local Storage in the left tree menu.
  4. Click on the domain to inspect or edit raw league JSON data in real-time.
